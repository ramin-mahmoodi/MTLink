# MTLink

**MTLink** یک کلاینت Native Android با Kotlin برای دریافت، مدیریت و آزمون پراکسی‌های عمومی Telegram است. رابط برنامه Dark Mode، فارسی/انگلیسی و مبتنی بر Viewهای Native Android طراحی شده است.

## قابلیت‌ها

- دریافت و استخراج پراکسی‌های MTProto و SOCKS5 از منبع‌های Text، JSON و HTML.
- مدیریت منبع‌ها، فعال/غیرفعال‌سازی، سقف مستقل هر منبع و اعمال سقف یک‌جا برای همهٔ منبع‌ها.
- آزمون اتصال مستقیم، وضعیت دسترسی، latency و تشخیص کشور IP هنگام آزمون.
- کپی، اشتراک‌گذاری، باز کردن در Telegram، QR و علاقه‌مندی‌ها.
- رابط دوزبانهٔ فارسی/انگلیسی با RTL واقعی و ذخیره‌سازی محلی.

## محتوای مخزن

این مخزن فقط شامل سورس Kotlin، منابع Android، Gradle Wrapper و آزمون‌های واحد است. فایل‌های APK، خروجی build، cacheهای Gradle، کلید امضا، تنظیمات محلی و داده‌های حساس عمداً در مخزن قرار نمی‌گیرند.
